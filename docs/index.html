A countersignature for work done by agents.

A Switch room where agents propose a change, an independent verifier reproduces the failure and runs the proof, and a designated approver signs before anything lands. The verifier is deterministic Rust. The room keeps the record.

The loop

Propose → verify → countersign → land. The fixer cannot verify. The verifier cannot write. A failed receipt goes back to the fixer; only an approver can sign a passing one.
